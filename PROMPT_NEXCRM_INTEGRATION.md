# Промпт для Cursor: интеграция NexCRM HTML в существующий сайт

Скопируй этот блок и вставь в чат Cursor вместе с приложенным HTML-файлом (или вставь HTML в следующем сообщении).

---

## Задача

Добавь в мой существующий сайт функциональность и интерфейс из приложенного HTML (NexCRM: лендинг, авторизация, дашборд с продуктами, заказами, клиентами, сотрудниками, аналитикой, настройками). Используй **только** те фреймворки и структуру, которые уже есть в проекте. Вся автоматизация (логика, сценарии, фичи) должна браться **только** из этого HTML — ничего нового не придумывай.

## Что уже есть в проекте

- **Frontend:** Vue 2.7, Vue Router, Vuex, Vuetify, Chart.js, vue-chartjs, vue-i18n.  
  Точка входа: `frontend/src/main.js`, корень: `frontend/src/App.vue`, маршруты: `frontend/src/router.js`.
- **Структура:** Есть маршруты `/login`, `/register`, `/home`, `/customer`, `/product`, `/settings`, `/tasks`, `/analytics/*`, `/team` и др. Для авторизованных показывается layout с сайдбаром (`Seidbar.vue`) и AppBar; для гостей — только `router-view` (логин, регистрация, verify-email).
- **Backend:** Express, SQLite, JWT. Есть API и сервис `frontend/src/services/api.js`, получение токена через `getAuthToken()`.

## Что нужно сделать

1. **Лендинг (NexCRM)**  
   Добавить маршрут лендинга (например `/` или `/landing`), если его ещё нет. Реализовать страницу по приложенному HTML: hero, блоки Features, Analytics (User Growth, Order Analytics), управление командой, Pricing, футер. Стили и вёрстку перенести в компоненты (Vue SFC или глобальные стили), не подключать Vue/Chart.js через CDN — использовать уже установленные пакеты.

2. **Авторизация**  
   Логику входа/регистрации из HTML подключить к **существующему** API (логин/регистрация через `api.js` и backend). Сохранить текущую навигацию после логина (редирект на `/home` или куда принято в проекте). Формы и тексты взять из HTML; при необходимости адаптировать под Vuetify, не меняя сценарии (поля, валидация «только из HTML»).

3. **Дашборд NexCRM**  
   Реализовать дашборд из HTML: сайдбар с пунктами (Dashboard, Products, Orders, Customers, Employees, Analytics, Settings), главный экран с карточками статистики (Revenue, Orders, Customers, Employees), блоки Revenue Overview и Recent Activity, графики (Chart.js через уже установленный vue-chartjs/Chart.js). Данные для дашборда брать из существующего API, где есть соответствующие эндпоинты; где нет — оставить моковые данные из HTML, но структуру оставить готовой к подстановке API.

4. **Разделы: Products, Orders, Customers, Employees**  
   Перенести из HTML таблицы и карточки (продукты, заказы, клиенты, сотрудники), модальное окно добавления продукта, кнопки удаления и т.д. Вся логика (какие поля показывать, какие действия есть) — только из HTML. Подключить к API проекта, если для этих сущностей уже есть запросы в `api.js`; иначе оставить локальное состояние как в HTML.

5. **Analytics и Settings**  
   Страницы аналитики (графики Revenue, Orders, Customer Growth и т.д.) и настроек (профиль, workspace) сделать по приложенному HTML. Графики — через Chart.js/vue-chartjs из проекта. Автоматизация только та, что описана в HTML (никаких новых отчётов или настроек).

6. **Стили и ресурсы**  
   Цвета, шрифты (Syne, DM Sans), градиенты и компоненты из HTML перенести в проект: либо в общие стили (например в `App.vue` или отдельный CSS/SCSS), либо в стили компонентов. Не добавлять новые CDN для Vue/Chart.js — только шрифты (Google Fonts) при необходимости.

7. **Ограничение**  
   Не добавлять фичи, которых нет в приложенном HTML. Вся автоматизация (сценарии, экраны, кнопки, поля форм) должна быть один в один из этого HTML; интеграция — только под твой текущий стек (Vue Router, существующий auth, API, Vuetify где уместно).

## Итог

После выполнения у меня должен быть: лендинг NexCRM, вход/регистрация через существующий backend, дашборд и все разделы из HTML (Dashboard, Products, Orders, Customers, Employees, Analytics, Settings), собранные на Vue 2, Vue Router, Vuetify и Chart.js из проекта, с автоматизацией только из приложенного HTML.
